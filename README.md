# MaxMotors

Site de închirieri și vânzări auto (HTML, CSS, JavaScript simplu, fără build).

## Rulare
Deschide `index.html` în browser sau rulează `python3 -m http.server` și mergi la http://localhost:8000.

## Pagini
`index.html` (principală), `cars.html` (listă + filtre), `car.html?id=octavia` (detalii/specificații), `sell.html` (adaugă mașină), `login.html`, `register.html`.

## Imagini
Pune pozele în `images/` cu numele `octavia.jpg`, `duster.jpg`, `clio.jpg`, `golf.jpg`, `corolla.jpg`, `panamera.jpg`.

## Date
Mașinile sunt în `js/app.js` (lista `CARS`).
